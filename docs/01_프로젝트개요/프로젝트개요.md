# 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | gesture-pc-assistant (개인 AI 비서) |
| 문서 기준일 | 2026-11-17 |
| 저장소 | https://github.com/JungUH-0/gesture-pc-assistant |
| 개발 기간 | 2026년 6월 ~ 진행 중 |
| 실행 환경 | Windows, Python 3.10, 웹캠, 마이크, NVIDIA GPU(음성 인식), Ollama |

## 1. 목적

키보드와 마우스 없이 손동작, 몸동작, 음성으로 PC를 제어하는 개인용 비서이다. 카메라와 마이크로 사용자의 입력을 인식하고, 로컬 LLM이 자연어 명령을 해석해 PC 동작으로 연결한다. 모든 처리는 사용자의 PC 안에서 이루어지며 외부 서버로 영상·음성을 보내지 않는다.

| 해결하려는 문제 | 접근 |
|---|---|
| 손이 닿지 않거나 자리를 비운 상태에서 PC를 조작하기 어려움 | 카메라 기반 손·포즈 인식과 음성 명령 |
| 제스처마다 동작을 코드로 고정하면 사용자가 바꿀 수 없음 | 자연어로 명령을 등록하고 LLM이 해석해 저장 |
| LLM이 PC를 직접 제어하면 위험함 | LLM은 해석만 하고, 실행은 허용 목록(화이트리스트)에 있는 동작만 수행 |

## 2. 주요 기능

| 구분 | 기능 | 내용 |
|---|---|---|
| 손동작 | 마우스 대체 | 커서 이동, 좌·우클릭, 드래그, 휠 스크롤 |
| 손동작 | 제스처 명령 | 스와이프 위/아래, 엄지 + 중지·약지·새끼 슬롯 3개, 손날 + 스와이프 다운(창 닫기 확인) |
| 손동작 | 예/아니오 | 엄지척 / 엄지다운 |
| 포즈 | 고개 신호 | 두 번 끄덕임(예), 두 번 가로젓기(아니오) |
| 포즈 | 자리 관리 | 자리 비움 / 복귀 감지 |
| 포즈 | 화면 캡처 | 양팔을 ㅡ자로 펴서 유지 |
| 음성 | 음성 명령 | 웨이크워드 또는 손등 3초 유지로 시작, Whisper로 변환 후 LLM이 해석·실행 |
| 명령 | 사용자 정의 명령 | 자연어로 등록(`이름: 하고 싶은 일`), 제스처·포즈 이벤트에 연결 |

세부 판정 조건과 값은 기능명세서에 정리했다.

## 3. 시스템 구성

| 구성 요소 | 역할 | 사용 기술 |
|---|---|---|
| 카메라 모듈 | 웹캠 영상에서 손 랜드마크를 읽어 제스처 판정 | OpenCV, MediaPipe Hands |
| 포즈 모듈 | 상체 랜드마크로 머리 동작·자리 비움·자세 판정 | MediaPipe Pose |
| 오디오 모듈 | 박수 감지 | sounddevice, 음량·스펙트럼 분석 |
| 음성 모듈 | 웨이크워드 감지, 명령 녹음, 문장 변환 | faster-whisper (medium) |
| 명령 모듈 | 자연어 해석, 명령 저장·실행 | Ollama (qwen2.5:3b-instruct), requests |
| PC 제어 | 마우스·키·창·앱·URL 실행 | pywin32 |
| 통합 실행 | 모듈을 스레드로 실행하고 신호를 통합, 모드 전환 | `main.py` |

손 인식과 포즈 인식은 동시에 돌리면 FPS가 크게 떨어지고 제스처끼리 충돌해서, **한 번에 하나만 켜는 모드 방식**으로 분리했다. 양손을 모아 1초 유지하면 모드가 전환된다.

처리 흐름은 플로우 차트 문서에 그림으로 정리했다.

## 4. 설계 원칙

| 원칙 | 내용 |
|---|---|
| 인식과 실행의 분리 | 인식 모듈은 신호만 만들고, 실제 동작은 `main.py`가 등록된 명령 또는 기본 동작으로 연결 |
| 안전한 실행 | LLM이 만든 문자열을 그대로 실행하지 않고 허용된 동작·대상만 실행. 창 닫기는 예/아니오 확인을 거치며 무응답이면 자동 취소 |
| 오인식 억제 | 신호는 새로 켜지는 순간에만 한 번 반응, 유지 시간·쿨다운·히스테리시스 적용, 손날 자세에서는 클릭류 판정 제외 |
| 로컬 처리 | 영상·음성·LLM 모두 사용자 PC에서 처리 |
| 한 곳에서 조정 | 판정 기준은 모듈 상단의 상수로 모아 두어 실측 후 조정 |

## 6. 개선 계획 (UI 전환)

현재는 콘솔과 카메라 창으로 실행된다. 일반 사용자가 쓰는 형태로 **트레이 앱**으로 전환할 계획이다.

| 항목 | 현재 | 목표 |
|---|---|---|
| 실행 형태 | 콘솔 + 카메라 창 | 트레이 아이콘만 상주 |
| 카메라 화면 | 항상 표시, 지표 겹침 | 기본 꺼짐, 켜면 랜드마크 점만 표시 |
| 명령 등록 | 콘솔 입력 | 설정창의 입력칸(LLM 해석) |
| 피드백 | 콘솔 로그 | 토스트 알림, 확인 팝업, 로그 파일 |

## 7. 알려진 제약

| 항목 | 내용 |
|---|---|
| 플랫폼 | Windows 전용 (`pywin32`) |
| GPU | 음성 인식이 CUDA에 고정되어 GPU가 없으면 실행이 어려움 (CPU 폴백 예정) |
| 포즈 모드 | 손 추적이 꺼져 마우스 제어·손 제스처 사용 불가 |
| 임계값 | 사용자·환경에 따라 조정이 필요한 값이 있음 |
| 외부 의존 | Ollama 설치와 모델 내려받기, Whisper 모델 첫 실행 시 내려받기(약 1.5GB) |
